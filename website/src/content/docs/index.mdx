A code map across **300+ languages**, and PDF, Office, HTML, email and image documents — one server does both jobs.

It also gives you semantic + full-text search, git history & blame, shared memory, and
agent-to-agent comms. Every answer comes back as **paths, line numbers, and signatures, not whole
files**, so a question about your code costs a small fraction of the tokens it takes to read the
source.

## The operating rule: basemind first, shell/grep/git fallback

<CardGrid>
    <Card title="Answer from structure" icon="magnifier">
        `code_outline` a file before you open it, `code_symbols` instead of
        grep, `code_refs` instead of grepping call sites. Pointers, not file
        bodies.
    </Card>
    <Card title="Ask history directly" icon="git-branch">
        `git_log`, `git_blame` and `git_diff` — git
        intelligence at symbol resolution, in tens of microseconds.
    </Card>
    <Card title="Search everything" icon="open-book">
        Semantic + full-text search over PDFs, Office, HTML, email, and images (OCR), with
        reranking and per-document summaries.
    </Card>
    <Card title="Coordinate agents" icon="comment">
        A shared channel for a team of agents on the same repo: threads, inboxes, invitation-only
        conversations, and orchestration of many subagents.
    </Card>
</CardGrid>

## Install in one step

The MCP plugin sets up the server, helper skills, comms, and slash commands — and downloads the
`basemind` program for you on first use. Pi uses the CLI and needs the program installed separately.
Or install the program directly with a package manager.
