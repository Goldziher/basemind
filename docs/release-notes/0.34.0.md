**The first scan after upgrading rebuilds every index and the blob store.** 0.34.0 bumps `RELEASE_MINOR` from 33 to 34 (`src/version.rs`), so each view's index and the group's Fjall index are reset at the first open, the blob store moves to `cache/blobs/v34/`, and every file is re-extracted and every document and code chunk re-embedded once. Run `basemind upgrade --plan` first to see the cost, and rebuild one worktree at a time. Read [`docs/UPGRADING.md`](https://github.com/Goldziher/basemind/blob/main/docs/UPGRADING.md) before installing.

This is a summary. The complete list of changes is the 0.34.0 section of [`CHANGELOG.md`](https://github.com/Goldziher/basemind/blob/main/CHANGELOG.md).

## Headline changes

- **One MCP tool per job (ADR-0018).** The mode-dispatched `code`, `git`, `memory` and `admin` tools are replaced by 15 tools with exact schemas and no `mode`: `code_outline`, `code_symbols`, `code_read`, `code_grep`, `code_search`, `code_refs`, `find_files`, `docs_search`, `git_log`, `git_blame`, `git_diff`, `memory_save`, `memory_search`, `index_status` and `index_rescan`. There are no aliases.
- **Agent comms v2 (ADR-0021).** The `agents` tool and the `basemind agents` CLI group are replaced by `agent_post`, `agent_inbox` and `agent_threads` and by `basemind agent post|inbox|threads|status|cleanup`.
- **Smaller answers.** The locating tools answer with rows as the shell prints them (ADR-0052), and the text block of `code_grep`, `code_outline`, `git_diff` and a `find_files` list is no longer JSON (ADR-0053).
- **The import graph and analysis commands.** `code_refs` lists a file's importers and the import cycles, and every call site says how it was resolved (ADR-0047). New CLI commands: `code impact`, `code cycles`, `code explain`, `code deadcode`, `code migration check`, `overview`, `git hotspots` and `sessions`.
- **Scoped and size-aware queries.** `changed` limits `code_grep`, `code_symbols`, `code_refs` and `find_files` to the files a change touched; `index_status` and `find_files` `min_lines` name the large files before they are opened.
- **One index per repository group (ADR-0028)**, shared by every worktree and view, and `docs_search` rebuilt on one document store per group (ADR-0029, ADR-0037), with the documentation of the repository's dependencies behind `[documents.dependencies]`.
- **Agent launch.** `basemind serve --lead` launches agents in worktrees of their own, off until the operator's `agents.toml` enables it (ADR-0040).
- **An offline manual**, `basemind manual [topic]`, compiled into the binary.
- **Removed:** web ingestion, agent shells, the code graph tool, the token-saving text tools, the `workspace` tool, memory audit and mining, archive extraction and LLM summarization.

## Breaking changes

CLI and configuration:

- `ranges` is gone from `code_grep`, `code_refs` and `code_read`, and from `code grep|refs|read --ranges`. Use `code_grep {context: N}` (a line count, 0 to 10).
- `path` is the one path filter of `code_grep`, `find_files` and `docs_search`: a repo-relative prefix, or a glob when it holds `*`. `find_files`' `path_prefix` and `--path-prefix` are renamed `path` and `--path`; `mcp/` no longer selects `src/mcp/tools.rs` in `code_grep`.
- `memory_search` takes `tags`, a list, where it took one `tag`; `basemind memory search|list --tag` is repeatable.
- `index_rescan`'s `full` argument and `basemind rescan --full` are removed; `index_rescan {}` is the whole workspace.
- `[documents.output] format`, `--documents-output-format` and `BASEMIND_DOCUMENTS_OUTPUT_FORMAT` are removed: the flag is rejected, so a host config that still passes it fails to start `basemind serve`.
- The shared worktree index of ADR-0016 (`BASEMIND_INDEX_LAYERED=1`), `BASEMIND_NO_SEED` and `scan --verify-shared-base` are removed; the group index replaces them. `BASEMIND_MCP_LEAN` and its wrapper tools are removed.
- Every boolean `BASEMIND_*` variable reads `1`, `true`, `yes`, `on` or `0`, `false`, `no`, `off`; any other value stops commands with an error naming the variable, and `false` now means false where it used to mean true (`BASEMIND_GRAMMAR_OFFLINE`, `BASEMIND_GIT_DISCOVER_PARENTS`).
- A non-loopback `BASEMIND_HTTP_ADDR` is refused unless `BASEMIND_ALLOW_HTTP_REMOTE=1` is set in the daemon's environment.
- `basemind init` without a terminal writes only with `--yes`.

MCP:

- The old tool names and the `mode` argument are gone; the `workspace` tool and worktree claims are removed.
- Lean rows on the locating tools, a `resolution` on each `code_refs` call site (a row that leaves it out has the page's `resolution_default`), and `structuredContent: {"error", "retryable"}` on every `isError` result change the shape of answers that scripts and prompts may parse.
- The verb tools refuse calls that can only come back empty and bound what they return.
- `docs_search` hits carry `chunk`, `cite`, `context`, `also_at` and `title`; `scope` and the per-hit `keywords`, `entities`, `summary`, `chunk_idx`, `distance` and byte offsets are gone.
- Comms protocol version 4 becomes 7 and the relay protocol 1 becomes 2: a client and a daemon of different versions refuse each other at connect. The agent store starts empty; threads and messages of earlier releases are not carried over.

Library: the public scan entries, the environment reads of the library (`BASEMIND_DATA_HOME` and others) and the process-wide engine configuration change; see the `BREAKING (library)` entries of the changelog.

## Upgrade notes

1. Check every boolean `BASEMIND_*` variable you set against the values above.
2. Update the plugin and the binary together, then restart every session. On a team, everyone who shares a checked-in `basemind.toml` upgrades before anyone adds a key new in 0.34 (`[analysis] entry_points`, `[documents.dependencies]`): 0.33 rejects unknown keys.
3. Run `basemind upgrade --plan` and `basemind scan`. A 0.33 daemon that still runs holds its repository's workspace lock and makes the scan fail with "already running against this repo": it exits ten minutes after its last client, or stop it with the 0.33 binary (`basemind comms stop`) before step 2.
4. Re-run `basemind init` (or `/bm-init`) in each repository with a basemind rules block, with `--yes` when there is no terminal, so the block routes agents to the verb tools.
5. Replace `permissions.allow` entries that name a retired tool or the `mcp__plugin_basemind_basemind__*` wildcard; `basemind init --settings-target local` (or `shared`) does it.
6. Update scripts and prompts for the tool renames and the `basemind agent` CLI; the mapping is in [`docs/UPGRADING.md`](https://github.com/Goldziher/basemind/blob/main/docs/UPGRADING.md).
